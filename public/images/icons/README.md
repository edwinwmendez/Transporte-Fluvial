# 🎨 Iconos

Carpeta para iconos personalizados y gráficos.

## 📋 Qué colocar aquí

- Iconos personalizados que no están en lucide-react
- Gráficos decorativos
- Ilustraciones pequeñas
- Iconos de funcionalidades específicas

## 📝 Ejemplos de nombres

```
icon-embarcacion.svg
icon-ruta.svg
icon-calendario.svg
icon-usuario.svg
```

## 💡 Nota

Para iconos comunes, considera usar `lucide-react` que ya está instalado en el proyecto.
Solo agrega iconos personalizados aquí si no están disponibles en la librería.
