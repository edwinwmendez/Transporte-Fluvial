# 🏢 Logos

Carpeta para logos de la empresa y branding.

## 📋 Qué colocar aquí

- Logo principal de Transporte Fluvial Atalaya
- Variantes del logo (horizontal, vertical, icono)
- Logos de partners o colaboradores
- Favicon y iconos de la aplicación

## 📝 Ejemplos de nombres

```
logo-transporte-horizontal.svg
logo-transporte-vertical.svg
logo-transporte-icon.svg
favicon.ico
apple-touch-icon.png
```

## 💡 Formatos recomendados

- **SVG** - Para logos vectoriales (escalables sin pérdida)
- **PNG** - Para logos con transparencia
- **ICO** - Para favicons
